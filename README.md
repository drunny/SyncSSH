# SyncSSH 1.0 - 带有 WebDAV 加密同步功能的 SSH 客户端

> SSH 客户端千千万，能把你的服务器资料一起带着走的，SyncSSH 想当其中那个更贴心的。

大家好，SyncSSH 是一个 SSH 客户端。顾名思义，它最初的设计重点就是“同步”。

很多时候，我们会在电脑 A 配好一堆服务器、跳板机、SFTP 路径和备忘录；换到电脑 B，就得重新配置一遍。复制粘贴、翻聊天记录、找旧截图……主打一个“记忆力大冒险”。

所以我做了 SyncSSH：把 SSH、SFTP、服务器备忘录和 WebDAV 加密同步放进同一个桌面应用里。你负责连接服务器，剩下的杂活交给它。快乐是我们的精神食粮，少配一次 SSH 就多快乐一点。✨

## 它能做什么？

- SSH 直连与单跳跳板机连接
- SFTP 文件浏览、上传、下载、编辑、重命名、删除与权限设置
- Markdown 服务器备忘录，支持图片、预览与 HTML 导出
- WebDAV 加密同步，在多台电脑之间恢复服务器资料
- SSH 主机指纹核对，拒绝“连错机器还不知道”的惊喜
- 终端复制、重连、清屏、多行命令，以及 Bash / Zsh 会话历史
- Linux 主机状态监控、连接计时、闹钟和周期休息提醒
- 白色主题与“纯黑绿字”主题：复古终端感，程序员 DNA 狠狠动了 🟩

## 下载与启动

Windows x64 便携版在 [Releases](../../releases) 页面下载。

下载 ZIP 后：

1. 完整解压，不要在压缩包里直接运行。
2. 双击 `SyncSSH.exe`。
3. 开始管理你的服务器。

不需要安装 Node.js，也不需要把电脑变成构建机。整个文件夹可以直接复制到另一台 Windows x64 电脑使用。

> 当前便携版未签名。Windows 弹出安全提示时，请确认下载来源确实是本仓库的 Release。

本地加密仓库默认保存在：

```text
%APPDATA%\SyncSSH\vault.json
```

## 第一次使用

### 1. 创建本地仓库

首次启动时设置主密码，至少 12 个字符。

这个密码用于加密本地资料。它不是 SSH 密码，也不是 WebDAV 密码；请认真保管，丢了暂时没有“忘记密码，给你发验证码”的温柔剧情。

### 2. 新建服务器连接

点击“新建连接”，填写：

- 服务器地址和端口
- SSH 用户名
- 密码，或可导出的 SSH 私钥
- 分组、所在地和备注

如果需要跳板机，先保存一条可直连的跳板连接，再在目标服务器的“SSH 跳板”中选择它。

首次连接时，请核对 SHA-256 主机指纹。指纹突然变了，不要条件反射点确认——先确认服务器是否真的换过密钥。安全这件事，宁可多看一眼，也别上演“我是谁、我在哪、我连到了谁”。

## WebDAV 加密同步

SyncSSH 的同步不是把账号密码明文扔进云盘，而是先在本地加密，再通过 WebDAV 同步。

远端可以看到的只有仓库标识、随机修订文件名、文件大小和访问时间；服务器资料、密码、私钥和备忘录内容都经过加密保护。

### 第一台电脑：创建远程仓库

1. 打开“同步设置”。
2. 填写 WebDAV 地址、账号和密码。
3. 选择“创建新的远程仓库”。
4. 输入本地仓库主密码。
5. 点击“保存并同步”。

SyncSSH 会在 WebDAV 目录中创建 `syncssh-v1` 子目录。

### 第二台电脑：恢复资料

1. 首次启动时选择“从 WebDAV 恢复”。
2. 填写同一个 WebDAV 地址和账号。
3. 输入第一台电脑使用的仓库主密码。
4. 恢复完成后，服务器资料和备忘录就会出现。

第一次在新电脑上连接服务器时，仍建议重新核对 SSH 主机指纹。同步的是资料，不是你的安全直觉。

### WebDAV 服务要求

WebDAV 目录需要支持：

- `GET`
- `PUT`
- `MKCOL`
- `PROPFIND`（Depth 1）
- `DELETE`
- 支持 `Overwrite: F` 的 `MOVE`

建议使用 HTTPS，并确保反向代理正确保留 `Destination` 请求头。

## SFTP：别只会 `scp`

SFTP 区支持：

- 浏览目录与根目录
- 上传、下载普通文件
- 新建文件和文件夹
- 重命名、复制路径、删除
- 查看和修改权限
- 双击编辑不超过 2 MiB 的 UTF-8 文本文件
- 按文件名过滤当前目录
- 下载目录时自动跳过符号链接和 Windows 不兼容文件名

远程文件编辑器会在保存前检查文件是否已被其他人修改，避免一不小心把同事的修改“顺手扬了”。文明运维，从我做起。

## 服务器备忘录

每台服务器都可以有独立 Markdown 备忘录，可用于记录：

- 部署命令
- 域名与路径
- 故障处理过程
- 常用 SQL
- “这个服务为什么不能碰”的祖传警告

支持 Markdown 预览、粘贴 PNG/JPEG/WebP/GIF 图片，并可导出为可直接打开的 HTML 文件。

终端中选中文字后，还可以直接追加到备忘录。灵感和报错日志，一个都别想跑。

## Linux 状态监控

在“状态”或“服务器监控”中启用 Linux 监控后，SyncSSH 会通过已验证的 SSH 通道定期采集：

- CPU、内存和磁盘状态
- 网络与磁盘 I/O
- 系统时间与运行情况

不需要额外开放端口，不需要再部署一套监控平台。小工具也可以有一点“我全都要”的气势。

普通用户默认使用 `~/.SyncSSH`，root 用户使用 `/root/.SyncSSH` 保存采集脚本。

## 终端小工具

- 标签页右键复制、重连、关闭
- 多行命令浮层
- 清屏与复制终端内容
- Bash / Zsh 会话历史
- 连接计时
- 闹钟与周期休息提醒

## 安全说明

- 本地仓库和每个远端修订都使用 scrypt 派生密钥与 AES-256-GCM 加密。
- SSH 主机指纹按设备保存；主机密钥变化时会中止连接。
- 仓库主密码、SSH 密码和 WebDAV 密码彼此独立。
- 当前不支持主密码找回、改密和历史压缩。

请定期备份 WebDAV 目录。服务器会挂、硬盘会坏、记忆会消失，但备份会让你在灾难发生时保持优雅。

## 当前限制

- 当前版本支持单跳跳板机。
- SFTP 文本编辑仅支持不超过 2 MiB 的 UTF-8 普通文件。
- 目前主要面向 Windows x64。
- 未签名构建可能触发 Windows 安全提示。

## 1.0 新功能

- 连接表单和 WebDAV 设置都有「测试连接」。首次 SSH 测试可在指纹对话框仅信任本次连接。连接所在地会随连接资料同步。
- 左侧顶部切换服务器、状态、备忘录和服务器总览。拖动连接到目标分组，点击组标题折叠，在连接菜单里复制配置。复制产生独立的新备忘录。HTML 导出包含当前备忘录草稿和可用的内嵌截图，导出的文件可直接打开。
- 「选项」可设置底色、终端背景和闹钟。闹钟使用本机时间和内置铃声，在应用运行期间提醒。周期休息会显示模糊遮罩，Esc 可提前结束。应用启动后可以关闭音频提醒。
- 终端标签右键复制、重连、关闭。使用浮层的多行命令及历史前，在空白提示符下点击「接入 Bash」或「接入 Zsh」。接入作用于当前交互会话，重连后可再次接入。历史留在本次会话内，并遵循 shell 的历史设置。多行命令在当前 shell 环境运行，回到提示符后自动收起。点击历史只回填，按回车才执行。
- SFTP 支持根目录、新建文件，并在文件表和目录树中共用「更多」操作。目录下载会跳过符号链接与 Windows 不兼容的文件名。目录删除会在确认后递归执行。
- 在「状态」或「服务器监控」启用 Linux 监控。安装前会显示远端位置。root 使用 /root/.SyncSSH，普通账户使用 ~/.SyncSSH。需要远端可执行 SSH 命令、可写安装目录以及 Linux 的 /proc 和常见 shell 工具。监控使用经过验证的后台 SSH 通道，每约 3 秒刷新，无需额外开放端口。启用状态按设备保存，停用后会断开采集连接，采集脚本留在远端目录。

## 第一次试用

1. 创建本地仓库。主密码至少 12 个字符，由你自行保管。每次启动用它解锁。
2. 先添加分组，再点「新建连接」。输入主机、SSH 用户和端口，选择密码或导入可导出的 SSH 私钥。私钥可以带口令。
3. 需要跳板时，先把跳板保存为可直连的连接。在目标连接的「SSH 跳板」下选择同一个跳板。可将它分配给多台目标机。
4. 点服务器开始连接。首次连接时对照可信渠道取得的 SHA-256 指纹，分别确认跳板和目标。任一指纹变化都会中止连接。合法轮换主机密钥后，可在左侧「状态 → 主机指纹」清除旧指纹，再重新核对。每台电脑单独维护已信任的指纹。
5. 右下可直接输入远程路径、展开目录树，按文件名过滤当前目录，上传与下载普通文件，或新建目录。双击 UTF-8 文件可编辑，用 Ctrl+S 保存。点「移到独立标签」或「与终端分屏」切换，编辑器保留草稿与选区，标签显示服务器及端口。
6. 左侧「备忘录」支持 Markdown、预览和粘贴 PNG、JPEG、WebP 或 GIF。终端中选中文字后点「选区追加到备忘录」，再点「保存备忘录」或用 Ctrl+S。在备忘录的下拉框选择任意已保存的服务器即可离线阅读，无需先打开 SSH 会话。

「跟随终端目录」依赖远程 shell 发送 OSC 7。若 shell 已配置，开启后会自动跟随。Bash 下可先交互试用下面的命令。确认可用后，可把它加入该服务器的 Bash 配置。示例保留 Bash 已有的 PROMPT_COMMAND，并对目录名做 URI 编码。

    syncssh_report_cwd() {
      local LC_ALL=C raw=$PWD encoded='' char hex i
      for ((i = 0; i < ${#raw}; i++)); do
        char=${raw:i:1}
        case "$char" in
          [a-zA-Z0-9._~/-]) encoded+=$char ;;
          *) printf -v hex '%%%02X' "'$char"; encoded+=$hex ;;
        esac
      done
      printf '\033]7;file://%s%s\007' "${HOSTNAME:-localhost}" "$encoded"
    }
    PROMPT_COMMAND+=(syncssh_report_cwd)

## 两台电脑使用同一个宝塔 WebDAV

1. 在宝塔站点上准备有读写权限的 HTTPS WebDAV 目录，例如 https://你的域名/dav/，从第一台电脑确认能访问。SyncSSH 会在该目录下创建 syncssh-v1 子目录。WebDAV 需要 GET、PUT、MKCOL、Depth 1 的 PROPFIND、DELETE，以及支持 Overwrite: F 的 MOVE。同站点反向代理要保留 Destination 请求头及正确的外部 URL，避免把 PROPFIND 或 MOVE 路由到普通网页。默认使用标准 TLS 证书校验。
2. 第一台打开「同步设置」，填 WebDAV 地址与账号，选择「创建新的远程仓库」，输入本地仓库主密码，点击「保存并同步」。成功后底栏显示「WebDAV 已同步」。
3. 第二台首次启动时选择「从 WebDAV 恢复」，填同一个地址和 WebDAV 账号，再输入第一台的仓库主密码。恢复后直接使用保存的 SSH 登录资料，首次连接仍需核对主机指纹。如果已经在第二台建立本地仓库，可以在同步设置中选「连接已有远程仓库并合并本地记录」。两边的仓库主密码须相同。
4. 可以用顶栏按钮手动同步。默认每 5 分钟同步一次，并在保存改动后同步。间隔设为 0 可以停用定时同步。网络不可用时，已在本地保存的改动会保留。打开「变更后自动同步」时，失败的待发送改动会退避重试。
5. 双方对不同记录的改动会汇合。未互相见到的同一记录变更会分别保留，在记录旁显示冲突入口。可查看各版本并选择保留项。同一记录按完整版本处理。创建远端仓库时，已有仓库标识受到保护。恢复模式先下载并验证，随后才创建本地仓库。

仓库主密码与 WebDAV 登录密码相互独立。本地仓库及远端每个修订分别使用 scrypt 派生密钥和 AES-256-GCM 加密。远端能看到仓库标识、随机修订文件名、大小和访问时间。远端存储应保留修订文件和仓库标识，可定期复制整个目录作备份。当前没有主密码找回、改密或历史压缩功能。

## 验证

    npm test
    npm run test:desktop

## 当前范围与发布

- 首版只有单跳。状态页显示会话、监控、指纹与同步情况。草稿和光标在打开的工作区中保留，退出前未保存的草稿会提示确认。
- SFTP 编辑支持不超过 2 MiB 的 UTF-8 普通文件，保存需要 OpenSSH 的 posix-rename 扩展。保存前检查远程内容，上传与下载以新文件方式创建。搜索范围是服务器清单和当前远程目录。
- 当前验证环境为 Windows 10 x64、两套隔离的应用配置和本地协议测试服务。另外使用 WsgiDAV 4.4.1 真实 WebDAV 服务验证了 Basic 认证、建库、发布、目录枚举、防覆盖及恢复。宝塔部署的 TLS、反向代理及 Linux OpenSSH 的实机组合需要进一步联调。后续可优先做真实服务器与两台物理电脑联调、测量大目录和慢链路表现，再做 macOS 打包和签名。
