# SyncSSH 1.2.0

- Windows x64 便携 ZIP。
- Ubuntu x64 DEB。首发构建以 Ubuntu 24.04 LTS 为基础。
- macOS Apple Silicon 预览 DMG，采用 ad hoc 签名，未经 Apple 公证。首次打开可能需要在「系统设置 → 隐私与安全性」为此应用确认。请先核对下载来源与 SHA-256。

SFTP 新增批量任务、进度、失败提示、取消、重试与普通文件断线续传。远程编辑新增本机加密草稿、重启恢复、远端冲突比对和另存副本。界面保留三区与 v1.1 的时钟、闹钟和布局。

先结束正在运行的旧版，再启动 1.2。现有加密仓库可继续解锁。
